\section{Špecifikácia požiadaviek}

\subsection{Funkčné požiadavky}

Systém Fluent Speech musí spĺňať nasledujúce funkčné požiadavky:

\begin{enumerate}
    \item \textbf{Nahrávanie a odosielanie videa} — mobilná aplikácia umožňuje zaznamenanie prezentácie s trojsekundovým odpočtom, ostrihnutie záznamu a jeho odoslanie na server.
    \item \textbf{Extrakcia kĺbových bodov} — server extrahuje 33 kĺbových bodov (MediaPipe Pose) z každého spracovávaného snímku videa a ukladá ich do databázy.
    \item \textbf{Transkripcia reči} — server transkribuje zvukový záznam do slov s časovými pečiatkami pomocou modelu Whisper.
    \item \textbf{Detekcia výplňových slov} — identifikácia výplňových slov (napr. \emph{ehm}, \emph{teda}, \emph{takže}) v transkripte na základe slovníkových vzorov a regex pravidiel.
    \item \textbf{Analýza výšky hlasu} — výpočet základnej frekvencie reči algoritmom YIN a detekcia monotónnych úsekov s nízkou variabilitou.
    \item \textbf{Analýza hlasitosti} — meranie hladiny energie v dBFS a detekcia úsekov, ktoré sú príliš tiché alebo príliš hlasné.
    \item \textbf{Analýza pohybu rúk} — sledovanie kinematiky zápästí a detekcia dlhých periód chýbajúcej gestikulácie a úsekov nadmerného pohybu.
    \item \textbf{Analýza pohybu bokov} — detekcia oscilácií bokov počas prezentácie na základe horizontálnych výchyliek kĺbových bodov.
    \item \textbf{Analýza očného kontaktu} — výpočet yaw a pitch uhlov hlavy z interaurálneho vektora a určenie percenta času, počas ktorého prezentujúci hľadel smerom k publiku.
    \item \textbf{Segmentácia časových radov} — detekcia výrazných štatistických zmien v analyzovaných signáloch algoritmom PELT prostredníctvom zdieľanej segmentačnej mikroslužby.
    \item \textbf{Hodnotenie prezentácie} — výpočet celkového skóre a skóre v štyroch dimenziách (hlas, plynulosť, očný kontakt, telo) a generovanie textových odporúčaní.
    \item \textbf{Zobrazenie výsledkov} — mobilná aplikácia zobrazuje skóre, štatistiky a zoznamy detekovaných udalostí s možnosťou seekovania prehrávaného videa na konkrétny timestamp.
\end{enumerate}

\subsection{Nefunkčné požiadavky}

\begin{itemize}
    \item \textbf{Modularita} — každá analytická funkcia je implementovaná ako samostatná mikroslužba s vlastným REST API rozhraním.
    \item \textbf{Konfigurovateľnosť} — parametre všetkých algoritmov sú nastaviteľné cez environmentálne premenné bez nutnosti rekompilácie.
    \item \textbf{Rozšíriteľnosť} — systém podporuje pridávanie nových analytických modulov bez zmeny existujúcich mikroslužieb.
    \item \textbf{Prenositeľnosť} — serverová časť je plne kontajnerizovaná pomocou Docker Compose.
    \item \textbf{Multiplatformnosť} — mobilná aplikácia je implementovaná vo Flutteri, čo umožňuje kompiláciu pre Android aj iOS z jedinej kódovej základne.
    \item \textbf{Offline nahrávanie} — záznam prezentácie nevyžaduje sieťové pripojenie; odosielanie na server prebieha až po dokončení záznamu.
    \item \textbf{Paralelné spracovanie} — analytický orchestrátor spúšťa analytické mikroslužby súbežne pomocou vlákien (\texttt{ThreadPoolExecutor}).
    \item \textbf{Odolnosť voči chybám} — zlyhanie jednej analytickej mikroslužby nepreruší ostatné analýzy; orchestrátor zaznamenáva neúspešné analýzy a pokračuje.
\end{itemize}

\section{Návrh systému}

\subsection{Architektúra}

Systém sa skladá zo štyroch logických vrstiev:

\begin{enumerate}
    \item \textbf{Mobilná aplikácia} (Flutter) — zachytáva video, odosiela ho na server a zobrazuje výsledky analýzy.
    \item \textbf{API brána} (Spring Boot / Kotlin, port 8000) — jediný vstupný bod pre mobilnú aplikáciu. Koordinuje volania na spracovateľský orchestrátor a analytický orchestrátor.
    \item \textbf{Spracovateľská vrstva} — mikroslužby zodpovedné za predspracovanie vstupných dát: extrakcia kĺbových bodov z videa, normalizácia a prevzorkovanie zvuku a transkripcia reči.

\end{enumerate}

\subsection{Konfigurácia prostredia}

Všetky konfigurovateľné parametre systému sú definované cez environmentálne premenné, ktoré Docker Compose načítava zo súboru \texttt{.env}. Premenné sú rozdelené do skupín:

\begin{itemize}
    \item \textbf{Databáza} — \texttt{DB\_HOST}, \texttt{DB\_PORT}, \texttt{DB\_NAME}, \texttt{DB\_USER}, \texttt{DB\_PASSWORD}
    \item \textbf{Whisper} — \texttt{WHISPER\_MODEL} (napr.\ \texttt{large-v3-turbo}), \texttt{WHISPER\_LANGUAGE}
    \item \textbf{MediaPipe} — \texttt{MIN\_DETECTION\_CONFIDENCE}, \texttt{MIN\_TRACKING\_CONFIDENCE}, \texttt{MODEL\_COMPLEXITY}, \texttt{FRAME\_INTERVAL}
    \item \textbf{Analýza hlasu} — prahové hodnoty pre hlasitosť v dBFS a citlivosť segmentácie
    \item \textbf{Analýza pohybu} — prahy pre gestikuláciu, z-score koeficient pre detekciu nadmerného pohybu, citlivosť segmentácie
    \item \textbf{Očný kontakt} — rozsahy zóny publika (\texttt{AUDIENCE\_YAW\_MIN/MAX}, \texttt{AUDIENCE\_PITCH\_MIN/MAX})
    \item \textbf{Výplňové slová} — prah počtu výplňových slov za minútu (\texttt{HIGH\_USAGE\_THRESHOLD})
    \item \textbf{Hodnotenie} — váhy dimenzií skóre (hlas 0,37; plynulosť 0,27; očný kontakt 0,27; telo 0,09)
\end{itemize}

Vzorová konfigurácia so všetkými premennými a ich predvolenými hodnotami je dostupná v súbore \texttt{.env.example}.

\section{Inštalácia a nasadenie}

\subsection{Predpoklady}

Pre nasadenie serverovej časti systému sú potrebné:

\begin{itemize}
    \item Docker Engine $\geq$ 24.0 a Docker Compose $\geq$ 2.20
    \item Minimálne 8\,GB operačnej pamäte (model Whisper \texttt{large-v3-turbo} vyžaduje cca 3\,GB)
    \item Minimálne 10\,GB voľného diskového priestoru (Docker obrazy + video súbory + model Whisper)
    \item Sieťový prístup pre počiatočné stiahnutie Docker obrazov a váh modelu Whisper
\end{itemize}

Pre vývoj alebo kompiláciu mobilnej aplikácie sú navyše potrebné:

\begin{itemize}
    \item Flutter SDK $\geq$ 3.9.0
    \item Android Studio (pre Android) alebo Xcode $\geq$ 14 (pre iOS)
    \item Fyzické zariadenie alebo emulátor s Androidom $\geq$ 7.0, resp.\ iOS $\geq$ 14.0
\end{itemize}

\subsection{Konfigurácia prostredia}

\begin{enumerate}
    \item Skopírujte vzorový konfiguračný súbor:
    \begin{verbatim}
cp .env.example .env
    \end{verbatim}
    \item Otvorte \texttt{.env} a nastavte minimálne tieto premenné:
    \begin{verbatim}
DB_PASSWORD=<zvolte_heslo>
WHISPER_MODEL=large-v3-turbo
    \end{verbatim}
    Ostatné predvolené hodnoty sú funkčné pre lokálne nasadenie.
\end{enumerate}

\subsection{Spustenie serverovej časti}

\begin{enumerate}
    \item Zostavte a spustite všetky kontajnery príkazom:
    \begin{verbatim}
docker compose up --build
    \end{verbatim}
    \item Počkajte, kým sa inicializuje databáza a načíta model Whisper. Pri prvom spustení môže tento krok trvať niekoľko minút.
    \item Overte dostupnosť API brány health check požiadavkou:
    \begin{verbatim}
curl http://localhost:8000/api/v1/health
    \end{verbatim}
    \item Pre zastavenie všetkých kontajnerov:
    \begin{verbatim}
docker compose down
    \end{verbatim}
    Pre zastavenie s vymazaním databázových dát pridajte príznak \texttt{-v}.
\end{enumerate}

\subsection{Spustenie mobilnej aplikácie}

\begin{enumerate}
    \item Prejdite do adresára mobilnej aplikácie a nainštalujte závislosti:
    \begin{verbatim}
cd fluent
flutter pub get
    \end{verbatim}
    \item Vygenerujte sieťové modely pomocou code generation:
    \begin{verbatim}
dart run build_runner build --delete-conflicting-outputs
    \end{verbatim}
    \item Spustite aplikáciu na pripojenom zariadení alebo emulátore:
    \begin{verbatim}
flutter run
    \end{verbatim}
    \item Adresu API servera nastavte v konfiguračnom súbore aplikácie tak, aby smerovala na IP adresu stroja, kde beží Docker Compose, s portom 8000. Pri testovaní na fyzickom zariadení musia byť server aj zariadenie v rovnakej sieti.
\end{enumerate}

\section{Používanie systému}

\subsection{Mobilná aplikácia}

Základný tok používania mobilnej aplikácie pozostáva zo štyroch krokov:

\begin{enumerate}
    \item \textbf{Nahrávanie prezentácie} — na domovskej obrazovke stlačte tlačidlo záznamu. Po trojsekundovom odpočte sa spustí nahrávanie. Po jeho ukončení sa zobrazí ukážka záznamu s možnosťou ostrihnutia začiatku a konca videa.

    \item \textbf{Odosielanie a sledovanie stavu} — video sa automaticky odošle na server po potvrdení záznamu. Na obrazovke detailu nahrávky sú zobrazené indikátory stavu troch fáz predspracovania: \emph{Video} (extrakcia kĺbov), \emph{Zvuk} (normalizácia) a \emph{Transkript} (prepis reči). V prípade chyby siete je možné nahrávku odoslať znova manuálne.

    \item \textbf{Spustenie analýzy} — po dokončení všetkých troch fáz predspracovania sa odblokuje tlačidlo \emph{Analyzovať prezentáciu}. Analýza zvyčajne trvá niekoľko sekúnd.

    \item \textbf{Prezeranie výsledkov} — po dokončení analýzy sú k dispozícii nasledujúce záložky výsledkov:
    \begin{itemize}
        \item \textbf{Skóre} — celkové skóre prezentácie, skóre jednotlivých dimenzií s váhami a textové odporúčania.
        \item \textbf{Štatistiky} — agregované číselné hodnoty pre každú analytickú oblasť (priemerná výška hlasu, percento očného kontaktu, počet výplňových slov a pod.).
        \item \textbf{Tematické záložky} — zoznamy detekovaných problémových udalostí (monotónnosť, hlasitosť, výplňové slová, pohyby rúk, pohyby bokov, očný kontakt). Kliknutím na udalosť sa video posunie na daný čas. Výrazné zmeny v signáli sú oddelené vizuálnym dividerom s časovým údajom.
    \end{itemize}
\end{enumerate}

\subsection{Priame API volania}

Pre integráciu s iným systémom alebo manuálne testovanie je možné ovládať systém priamo cez REST API. Typická sekvencia volaní:

\begin{enumerate}
    \item \textbf{Nahratie video súboru:}
    \begin{verbatim}
POST http://localhost:8000/api/v1/processing/upload
Content-Type: multipart/form-data
video=<video_subor.mp4>
    \end{verbatim}
    Odpoveď obsahuje \texttt{id} nového záznamu, ktoré sa použije v ďalších volaniach.

    \item \textbf{Kontrola stavu predspracovania} (opakovane, kým sú všetky príznaky \texttt{true}):
    \begin{verbatim}
GET http://localhost:8000/api/v1/processing/status/{id}
    \end{verbatim}

    \item \textbf{Spustenie komplexnej analýzy:}
    \begin{verbatim}
POST http://localhost:8000/api/v1/analysis/analyze?recording-id={id}
Content-Type: application/json

{
  "arm_movement": true, "eye_contact": true,
  "pitch": true,        "volume": true,
  "hip": true,          "filler_words": true
}
    \end{verbatim}
    Odpoveď je JSON objekt s kľúčom \texttt{results} obsahujúci výstupy jednotlivých mikroslužieb a kľúčom \texttt{performance} s celkovým skóre a odporúčaniami.
\end{enumerate}
