\section{Architektúra a mikroslužby}

Síce architektúra už bola opísaná v hlavnej časti dokumentu, táto časť opisuje ich nasadenie a konfiguráciu.

Systém sa skladá zo štyroch logických vrstiev:

\begin{enumerate}
    \item \textbf{Mobilná aplikácia} (Flutter) — nahráva video, odosiela ho na server a zobrazuje výsledky analýzy.
    \item \textbf{API brána} (Spring Boot / Kotlin, port 8000) — jediný vstupný bod pre mobilnú aplikáciu. Koordinuje volania na spracovateľský orchestrátor a analytický orchestrátor.
    \item \textbf{Spracovateľská vrstva} — mikroslužby zodpovedné za predspracovanie vstupných dát: extrakcia kľúčových bodov z videa, normalizácia a prevzorkovanie zvuku a transkripcia reči.
    \item \textbf{Analytická vrstva} — mikroslužby vykonávajúce špecializované analýzy nad predspracovanými dátami uloženými v zdieľanej databáze.
\end{enumerate}

Prehľad všetkých mikroslužieb so zodpovedajúcimi portmi je uvedený v tabuľke~\ref{tab:td-microservices}.
Tieto porty sú konfigurovateľné pomocou premenných prostredia.

\section{API rozhrania}

V tejto sekcii opíšem api rozhrania jednotlivých mikroslužieb a API Gateway.
Všetky príkladné požiadavky sú zároveň napísané v súbore requests.http, ktorý je súčasťou príloh práce.

\subsection{API gateway (port 8000)}

Mobilná aplikácia komunikuje výhradne s API bránou. Dostupné endpointy sú uvedené v tabuľke~\ref{tab:td-api-gateway}.

\begin{table}[ht]
\centering
\caption{Endpointy API brány}
\label{tab:td-api-gateway}
\begin{tabularx}{\textwidth}{|X|X|X|}
\hline
\textbf{Metóda} & \textbf{Cesta} & \textbf{Popis} \\
\hline
POST & \texttt{/api/v1/processing/upload} & Nahratie video súboru (multipart/form-data) \\
GET  & \texttt{/api/v1/processing/status/\{id\}} & Stav spracovania záznamu \\
POST & \texttt{/api/v1/analysis/analyze?recording-id=\{id\}} & Spustenie analýzy \\
\hline
\end{tabularx}
\end{table}

Telo požiadavky na endpoint spustenia analýzy je JSON objekt umožňujúci selektívnu aktiváciu jednotlivých analytických modulov:

\begin{verbatim}
POST /api/v1/analysis/analyze?recording-id=49
Content-Type: application/json

{
  "arm_movement": true,
  "eye_contact":  true,
  "pitch":        true,
  "volume":       true,
  "hip":          true,
  "filler_words": true
}
\end{verbatim}

Nastavením hodnoty \texttt{false} pre konkrétnu oblasť je možné vynechať jej analýzu a skrátiť čas spracovania.

\subsection{Konfigurácia prostredia}

Všetky konfigurovateľné parametre systému sú definované cez environmentálne premenné, ktoré Docker Compose načítava zo súboru \texttt{.env}. Premenné sú rozdelené do skupín:

\begin{itemize}
    \item \textbf{Databáza} — \texttt{DB\_HOST}, \texttt{DB\_PORT}, \texttt{DB\_NAME}, \texttt{DB\_USER}, \texttt{DB\_PASSWORD}
    \item \textbf{Whisper} — \texttt{WHISPER\_MODEL} (napr.\ \texttt{large-v3-turbo}), \texttt{WHISPER\_LANGUAGE}
    \item \textbf{MediaPipe} — \texttt{MIN\_DETECTION\_CONFIDENCE}, \texttt{MIN\_TRACKING\_CONFIDENCE}, \texttt{MODEL\_COMPLEXITY}, \texttt{FRAME\_INTERVAL}
    \item \textbf{Analýza hlasu} — prahové hodnoty pre hlasitosť v dBFS a citlivosť segmentácie
    \item \textbf{Analýza pohybu} — prahy pre gestikuláciu, z-score koeficient pre detekciu nadmerného pohybu, citlivosť segmentácie
    \item \textbf{Očný kontakt} — rozsahy zóny publika (\texttt{AUDIENCE\_YAW\_MIN/MAX}, \texttt{AUDIENCE\_PITCH\_MIN/MAX})
    \item \textbf{Výplňové slová} — prah počtu výplňových slov za minútu (\texttt{HIGH\_USAGE\_THRESHOLD})
    \item \textbf{Hodnotenie} — váhy dimenzií skóre (hlas 0,37; plynulosť 0,27; očný kontakt 0,27; telo 0,09)
\end{itemize}

Vzorová konfigurácia so všetkými premennými a ich predvolenými hodnotami je dostupná v súbore \texttt{.env.example}.

\section{Inštalácia a nasadenie}

\subsection{Predpoklady}

Pre nasadenie serverovej časti systému sú potrebné:

\begin{itemize}
    \item Docker Engine $\geq$ 24.0 a Docker Compose $\geq$ 2.20
    \item Minimálne 8\,GB operačnej pamäte (model Whisper \texttt{large-v3-turbo} vyžaduje cca 3\,GB)
    \item Minimálne 10\,GB voľného diskového priestoru (Docker obrazy + video súbory + model Whisper)
    \item Sieťový prístup pre počiatočné stiahnutie Docker obrazov a váh modelu Whisper
\end{itemize}

Pre vývoj alebo kompiláciu mobilnej aplikácie sú navyše potrebné:

\begin{itemize}
    \item Flutter SDK $\geq$ 3.9.0
    \item Android Studio (pre Android) alebo Xcode $\geq$ 14 (pre iOS)
    \item Fyzické zariadenie alebo emulátor s Androidom $\geq$ 7.0, resp.\ iOS $\geq$ 14.0
\end{itemize}

\subsection{Konfigurácia prostredia}

\begin{enumerate}
    \item Skopírujte vzorový konfiguračný súbor:
    \begin{verbatim}
cp .env.example .env
    \end{verbatim}
    \item Otvorte \texttt{.env} a nastavte chýbajúce hodnoty premenných
\end{enumerate}

\subsection{Spustenie serverovej časti}

\begin{enumerate}
    \item Zostavte a spustite všetky kontajnery príkazom:
    \begin{verbatim}
docker compose up --build
    \end{verbatim}
    \item Počkajte, kým sa inicializuje databáza a načíta model Whisper. Pri prvom spustení môže tento krok trvať niekoľko minút.
    \item Overte dostupnosť API brány health check požiadavkou:
    \begin{verbatim}
curl http://localhost:8000/api/v1/health
    \end{verbatim}
    \item Pre zastavenie všetkých kontajnerov:
    \begin{verbatim}
docker compose down
    \end{verbatim}
    Pre zastavenie s vymazaním databázových dát pridajte príznak \texttt{-v}.
\end{enumerate}

\subsection{Spustenie mobilnej aplikácie}

\begin{enumerate}
    \item Prejdite do adresára mobilnej aplikácie a nainštalujte závislosti:
    \begin{verbatim}
cd fluent
flutter pub get
    \end{verbatim}
    \item Vygenerujte sieťové modely pomocou code generation:
    \begin{verbatim}
dart run build_runner build --delete-conflicting-outputs
    \end{verbatim}
    \item Spustite aplikáciu na pripojenom zariadení alebo emulátore:
    \begin{verbatim}
flutter run
    \end{verbatim}
    \item Adresu API servera nastavte v konfiguračnom súbore aplikácie tak, aby smerovala na IP adresu stroja, kde beží Docker Compose, s portom 8000. Pri testovaní na fyzickom zariadení musia byť server aj zariadenie v rovnakej sieti.
\end{enumerate}
